# Change Records

Every request gets a directory under this path using `CHG-YYYYMMDD-NNN-slug`.

Required files are `summary.md`, `requirements.md`, `review.md`, and `memory.md`. Plan and complex Changes also require `architecture.md`, `plan.md`, and `ci.md`. Complex releases require `post-release-review.md`.

Change records are durable development memory. Never store credentials or sensitive production data.
