# Core Rules

- User instructions take priority; a more specific `AGENTS.md` takes priority over generic rules.
- Understand the current state before editing; make a verifiable plan before risky actions.
- Protect existing user changes. Do not reset, overwrite, or clean unrelated files.
- Make only the smallest change required by the task.
- Separate facts, inferences, assumptions, and unverified items.
- Never expose passwords, tokens, private keys, complete environment files, or personal data.
- Every stage must leave traceable evidence.
- Do not claim verification without a test; do not claim releasability without rollback.
