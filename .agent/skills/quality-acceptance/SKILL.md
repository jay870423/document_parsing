# Skill: Quality Acceptance

Review evidence independently instead of trusting verbal claims. Check the implementation task graph, dependency ordering, parallel write scopes, conflict resolution, and CI artifacts.

Prioritize startup, core APIs, data read/write, authentication, authorization, and key user flows. Then review boundaries, compatibility, security, performance, and operations.

Severity levels are blocker, high, medium, and low. Use `.agent/templates/acceptance-report.md` and keep the conclusion consistent with evidence.
