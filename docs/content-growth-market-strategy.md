# 内容增长工作台：产品闭环、付费转化与能力边界

> 版本：2026-11-25。本文是产品与技术共同验收基线，不把规划写成已上线能力。
>
> 状态标记：**[已实现]** 表示候选代码已有实现和回归测试；**[待发布]** 表示仍需生产迁移与公网验收；**[规划]** 表示尚未开发，禁止用于销售承诺。

## 1. 产品定位

面向有持续内容生产需求的教育、知识与专业服务人员，提供“基于自己的文章与授权参考资料，生成可追溯来源的选题和草稿”的工作台。

核心差异不是“一键 AI 写文”，而是：

1. 先学习本人文章，风格草稿必须人工确认后才会用于成稿。
2. 选题简报区分结构分析、数据事实、模型观察和数据限制。
3. 草稿带 `[R1]` 等来源编号、引用映射、待核实事实与风险提示。
4. 人工修改正文后，旧引用映射明确作废；导出保留历史来源并显示“引用尚未重新核验”警告，避免悬空引用。
5. 不自动发布，不伪造阅读、分享、关注或付费数据，不把描述性指标包装成因果结论。

**北极星建议：[规划]** 每周“完成人工核对并导出”的循证草稿人数，而不是 AI 调用量。只有导出前的质量动作进入北极星，才能避免用生成量掩盖低采用率。

## 3. 付费设计与首次激活

### 3.1 代码中已存在的统一额度

以 `app/billing.py` 的 `PLAN_SEEDS` 为唯一价格源：

| 套餐 | 当前代码价格与额度 |
| --- | --- |
| 新人免费体验包 | 0 元，3 次，365 天有效 |
| 个人轻量版 | 9.9 元/月，100 次 |
| 个人标准版 | 19.9 元/月，300 次 |
| 专业增强版 | 49.9 元/月，1000 次 |

内容增长的风格分析、选题简报、证据化成稿均为**每次成功生成扣 1 次，失败自动退回**。浏览已有来源、文章、历史任务和导出不另扣内容生成次数。额度与文档解析、检索/问答等现有能力共享，销售页不得把总额度承诺成“固定可写多少篇文章”。

### 3.2 三次免费额度正好完成一次价值闭环

首次引导固定为三步，而不是让用户从空白页自己摸索：

1. 录入本人文章并生成风格草稿：第 1 次成功调用。
2. 激活风格并生成选题简报：第 2 次成功调用。
3. 选择简报主题并生成证据化草稿：第 3 次成功调用。

三步完成后，用户已体验“我的素材 → 我的风格 → 有来源的可编辑草稿”。失败不消耗激活机会；网络重试必须沿用 operation ID，不能重新扣费。

### 3.3 付费墙原则

- 余额为 0 时，在请求 AI 前返回 402；保留主题、补充要求和当前编辑内容，不清空表单。
- 文案必须写明“本次尚未请求 AI、未扣费”，提供套餐/兑换入口；支付或发码完成后从原工作台继续。
- 付费请求先持久化 operation ID，再发 POST；存储不可用、写入后读回不一致时失败关闭，不能冒险请求 AI。
- 已生成并扣费、仅列表刷新失败时，明确显示“结果已保存”，提供“仅刷新工作台”，不得诱导再次生成。
- 当前没有在线支付收单与自动续费闭环时，页面只能提供真实可用的后台发放/兑换路径，不能展示假的“立即支付成功”。

### 3.4 是否另设“内容增长专属套餐”

**[规划] MVP 阶段不另起价格体系。** 先复用统一额度，观察完整漏斗后再决定是否按“成功导出的循证草稿”设计价值套餐。任何新价格必须同时修改套餐单一事实源、购买页、兑换规则、额度说明和测试，禁止只改宣传数字。

如未来与“兴趣学习岛”会员打通，应建立明确的产品权益映射和跨产品身份映射；当前本项目订阅表不等于 `parent_membership`，不得宣称已经一码通用。

## 4. 上线后必须先看的数据

**[规划]** 在调整入口、价格或按钮之前，先补并对齐以下埋点；测试账号和爬虫流量必须剔除：

- 首次本人文章保存率。
- 风格生成成功率、人工激活率。
- 简报生成成功率、简报被用于成稿的比例。
- 草稿生成成功率、人工编辑率、导出率。
- 402 到达率、402 后真实兑换/开通率。
- 网络重试率、同 operation 重放率、异常恢复率。
- 7/30 天再次导出率；按套餐、来源渠道和设备拆分。

每次改动只调整一个主变量，并保留改动前后的同口径数据。小样本只用于发现问题，不用于宣布增长结论。

## 5. 获客与传播边界

- 朋友圈/私域内容展示“来源可追溯 + 人工核对 + 不自动发布”的真实差异，不使用“保证爆文”“自动提升转化率”等无法证明的承诺。
- 演示素材必须使用自有、授权或明确的虚构示例；真实用户文章与指标默认不可作为公开案例。
- 公众号未认证或接口权限不足时，不承诺自定义微信分享卡片；代码无法绕过微信权限限制。
- 不使用营销短信作为增长兜底；通知优先走产品内真实可达入口。

## 6. 微信读书能力边界

### 6.1 当前可以交付的路径

本项目当前解析器实际支持：PDF、DOC/DOCX、TXT、Markdown。用户对自己拥有或获授权的内容，可通过现有文档入口导入这些格式，再进入知识库流程。

**微信读书书架、阅读进度、阅读时长、笔记和划线的自动读取，当前没有已完成并验证的官方 API 集成。** 因此：

- 不显示“连接微信读书”“一键同步书架/笔记”的可用按钮。
- 不承诺获取好友书架、阅读排名或任何非本人授权数据。
- 不接受用户微信 Cookie、抓包令牌作为生产集成方案。
- 不逆向客户端、不绕过 DRM/访问控制、不批量搬运受版权保护的书籍内容。

### 6.2 临时人工导入方案

**[规划]** 若用户能从微信读书合法导出或自行整理自己的笔记，可先复制为 TXT/Markdown，再按现有文本导入能力处理。导入界面需明确：

1. 这是用户主动提供的内容，不是系统自动同步。
2. 只导入本人笔记或已获授权文本；整本受版权保护书籍不进入公共素材库。
3. 当前未验证 EPUB 解析，不能把 EPUB 写成已支持格式。
4. 原书观点与 AI 推断必须分栏，引用回原文位置后才能进入循证草稿。

### 6.3 未来官方集成闸门

只有取得可核验的官方开发文档、应用权限和用户 OAuth 授权流程后，才允许立项 Spike。验收必须覆盖权限最小化、撤回授权、令牌安全存储、字段映射、速率限制、删除同步、版权隔离和真实账号回归。任何一项缺失都继续保留“未接入”状态。

## 7. 分阶段路线

### P0：本次发布闸门

- 生产显式迁移 6 张内容增长表，迁移前预检、迁移后只读核验。
- 全量测试、内容增长专项、真实浏览器和公网隔离验收通过。
- 风格/简报/草稿幂等、防重复扣费、失败退款、崩溃检查点恢复、KB/用户隔离无阻断项。
- 人工编辑不会被生成、打开、保存响应或 KB 切换静默覆盖。
- 临时公网验收账号与数据级联清理，并复查残留为 0。

### P1：发布后再做，未做不得宣传

- 首次三步激活引导与 402 后继续原任务的产品化页面。
- 真实可用的购买/兑换入口和到期、剩余次数的清晰展示。
- 上述激活与付费漏斗埋点、爬虫/测试流量过滤。
- 基于真实使用数据修订 onboarding，而不是先加更多入口。

### P2：经验证需求后立项

- 官方公众号数据授权同步；同步前仍只支持人工指标。
- 官方发布接口集成；集成前仍只支持导出与人工发布。
- 微信读书官方授权 Spike；未完成前仍明确“未接入”。
- 团队审阅、批注、品牌模板和跨产品会员权益，均不得写成现有功能。

## 8. 产品验收话术

每次交付必须分别回答：

1. **完成**：具体 URL/页面、测试数量、截图或 DOM 证据、生产数据清理结果。
2. **未做**：在线支付、自动发布、自动指标同步、微信读书同步等真实边界。
3. **残余风险**：例如硬崩溃后检查点的租约等待，不得用“全部绝对安全”掩盖。
4. **下一步**：只列有触发条件、负责人和验收标准的动作；没有排期的想法标为规划，不冒充任务进度。
